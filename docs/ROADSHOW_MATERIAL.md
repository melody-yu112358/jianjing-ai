# Phase 6 · 决赛路演素材与操作手册

## 入口与表达边界

- 决赛入口：`/roadshow`；首页“进入决赛演示”可直接到达。
- 主案例默认“脑子停不下来”，选择状态后点击“一键开始 · 60 秒”。总览、模拟个人参考与短路径在播放前已经可见，不需要逐页点确认。
- “已经比较困”是 **30 秒**短路径：省去固定节拍并提前退出。切换状态需先重置，避免中途更换案例。
- 固定模拟信号、预设决策回放、相同时间得到相同控制。此页面不调用 LLM、不请求后端、不使用真实个人历史。它演示 Agent 闭环的产品行为，不能作为本场实时推理或生理有效性的证据。
- 真实后端连接与 Explainability API 集成仍在首页，技术问答时可打开；不同演示来源不要混称。
- 只交付页面、文档和素材建议，**不制作 PPT**。

## 60 秒时间线与主持人口播

| 时间 | 屏幕重点 | 主持人口播提示 | 技术解释点 |
|---|---|---|---|
| 开始前 | 选择今晚状态；模拟个人参考 72–80 心率、12–16 呼吸；短路径 | “今晚脑子还停不下来。系统先看此刻和个人参考有什么不同。” | 个人参考是预置历史，不是这个观众的真实数据 |
| 0–8s | 交织光丝；状态总览；初始读数与参考范围 | “这段是固定模拟案例。我们重点看：状态变化之后，下一步有没有改变。” | 同一回放时钟驱动信号、解释、控制 |
| 8–10s | 短路径生成：尝试一轮，再观察 | “它先安排一轮慢呼气，不预先承诺做完整套课程。” | 有限动作空间，阶段决策 |
| 10–20s | 外层按 4 秒吸、6 秒呼开合，内层回应状态 | “外层是引导节拍，内层是状态反馈，两者不是同一件事。” | 呼吸节拍与反馈分层；声音提示共用时间线 |
| 20–22s | 短暂下降后，模拟读数重新上升 | “这里出现了回升，所以它不会机械重复上一轮。” | 不只看一个数值，观察连续变化 |
| 22–38s | 动作切换，取消固定节拍，声音关注；Decision Trace 新节点 | “当前方式暂未带来清晰的趋稳，换一个任务感更低的方法。” | 观察 → 依据 → 动作；身体紧绷案例改为自然呼吸 |
| 38–50s | 光丝扰动和运动速度下降；状态开始趋稳 | “看到变化趋稳后，它减少口令，不再增加任务。” | 视觉为确定性映射；不由 LLM 直接写 shader |
| 50–54s | 跳过额外练习，短路径结束准备 | “最重要的决定，是不再要求用户继续做。” | 减少刺激与退出是动作空间的一部分 |
| 54–60s | 海浪渐弱、光丝淡出；决策足迹保留 | “它会主动结束，而不是用更多互动把人留住。” | 同一时钟上的视觉与声音淡出 |
| 60s 后 | “今晚不用再看我了”；前后变化与决策足迹可回看 | “我们展示的是按状态改变引导的闭环；这不代表已经入睡或干预有效。” | 结束不是睡眠阶段判断，模拟不是实测 |

主持人完整口播尽量控制在 45–50 秒，留出开场和最后淡出的静默。讲解时可在技术设置关闭中文语音，只保留低音量海浪；不要与语音同时抢话。

## 30 秒补充案例

选择“已经比较困”，展示无需完整呼吸课程。0 秒保留自然呼吸，25 秒跳过额外练习，27–30 秒淡出并结束。说明这是路演时间压缩，不是医学上确定的干预时长。该路径不出现固定呼吸节拍，不经过高扰动 storm 视觉。

## 页面结构与画面素材

1. 顶部：品牌、模拟来源标识、全屏入口。
2. 主区域左侧：双层生命光丝、一句引导、播放与声音控制。
3. 主区域右侧：今晚状态／AI 状态理解、观察依据、下一步、参考比较。
4. 底部：随时间出现的决策足迹，形成变化原因的证据链。
5. 次级折叠区域：未来传感能力；技术模式和声音设置。默认不显示原始状态字段或开发连接信息。

投屏优先横屏 1920×1080 或 1366×768，使用“切换全屏投影”或浏览器全屏。窗口较窄时自动上下排列；投影仪必须现场确认字号与亮度。视觉保留雾蓝与暖金双层光丝，不新增游戏化元素。

## 截图建议（人工制作 PPT 时使用）

- 开始前：今晚总览 + 模拟参考 + 短路径，说明输入如何影响安排。
- 14s：呼气顶点，画面包含“内层回应状态 / 外层引导呼吸”。
- 22–24s：最重要的一张；捕捉“暂未趋稳，改变方式”、当前读数、下一步与决策足迹。
- 50–52s：减少刺激与跳过练习。
- 60s：主动退出和决策足迹；不要仅截一张漂亮光球。
- 30 秒短路径终点：与标准案例并列，表达“不必做满同一套课程”。

截图与录屏始终保留“模拟信号 · 预设决策回放”。PPG 录屏单独标“实验性采集原型，尚未稳定获得有效心率”，不能剪接成当前读数来自手机。

## 易拉宝信息层级

- 远看：渐静；“熄灯前最后三分钟的 AI 闭环睡前仪式”。
- 核心一句：不是告诉你怎么呼吸，而是根据你的身体有没有真的慢下来，实时改变引导。
- 中层主图：一张双层光丝配“观察 → 判断 → 调整 → 主动退出”的四步结构。
- 三个证据点：未趋稳会换方式；已经较困会缩短路径；结束时主动降低刺激。
- 技术小图：Sensor/Simulator → State Engine → Controller → Visual Mapper → Frontend；仅标实际已实现内容。
- 底部状态：当前决赛案例为模拟回放；手机 PPG 原型待验证；可穿戴与长期个人参考是后续接入方向。
- 链接/二维码：由人工使用最终确认的演示 URL 生成；本文件不虚构公网地址。
