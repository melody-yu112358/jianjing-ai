# 渐静 · 心中有光

本轮基于用户提供的五张艺术参考，重新设计首页：全屏色彩空间、柔和内光、固定空间颗粒、连续光流。画面为参数驱动的程序化视觉，没有直接使用参考图片作背景。

## 已实现

- 五个独立画境：晴空、流光、远日、暖境、环抱。选画境保留当前生理状态与引导，不重置会话。
- 首页为练习界面；数据、动画参数及 WebSocket 连接在侧栏。旧完整界面保留于 `/lab`。
- 复用原有 v1/v2 协议解析、消息顺序校验、自动重连、人工接管、40 秒时间戳回放和会话内入睡事件去重。
- 画境可跟随原有模式，映射为 serenity→晴空、storm→流光、fold→暖境、ripple/pulse→环抱。远日可手选。关闭自动切换只固定画境，连续参数仍响应。
- 模式重定向从屏幕当前混合权重继续；统一平滑数值、色层与粒子/流线速度。
- sleep_detected 后停止引导，六秒内色光收敛为暗色空间，普通帧不能重新唤醒画面。
- WebGL 不可用显示文字与重试按钮；画面上限约 30fps、像素比最高 1.35；系统减少动态偏好启用轻柔动效。
- 独立 HTML 由相同 React 首页与构建 CSS 打包，包含依赖，不需要下载外部图像或代码。构建后运行 `node scripts/export-inner-light.mjs /absolute/output.html`。

## 参数对应

| 参数 | 新视觉中的作用 |
|---|---|
| intensity | 细流的可见程度 |
| noise / turbulence | 连续色流的局部交叠 |
| speed | 色层变化速度 |
| deformation | 光流弯曲与轮廓起伏幅度 |
| frequency | 细流疏密 |
| glow | 内部微光亮度 |
| pulse | 环抱光晕的呼吸幅度 |
| particle_* | 星点密度、分散、速度、尺寸和亮度 |
| line_* | 细流密度、幅度、速度和亮度 |
| hue | 克制的冷暖偏移，不覆盖参考画境的主配色 |
| transition_sec | 连续指数平滑的时间尺度，约在该时间内完成 98% 变化（最低 1 秒） |
