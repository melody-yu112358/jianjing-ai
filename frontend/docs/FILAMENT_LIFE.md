# 渐静 · 光丝生命体

## 本轮设计

用户选定静态概念 ①「光丝生命体」，要求图形以外回到第一版界面。本轮首页恢复左侧体验、右侧状态与调节的双栏结构，保留原有标题、呼吸引导、播放、重置、趋势、稳定度与模拟状态滑块。精细光丝/粒子控制和回放记录折叠展示。上一版水波体验仍在 `/lab`。

主体为实时三维几何，不使用概念图贴图替代动画。雾蓝、桃金、淡紫及少量青绿沿空间光丝分布。主体有基础光丝、可调增强光丝、独立粒子和内光四部分。

## 已实现

- 在单位球面切向流场上积分出连贯曲线，形成有内部层次的球状生命体。
- 宽屏 520 条光丝，每条 176 段；窄画布 320 条，每条 144 段。可见画布按宽度调整相机，主体不会随窄屏被简单裁切。
- 宽屏最多 3000 个点，窄画布 1800 个点；实际可见数量由参数控制。
- 参数平滑与模式混合沿用已有 `ModeTransition`；快速切换从当前形态继续。
- 轻柔模式降低形变与速度；页面隐藏时不绘制；WebGL 失败提供文字引导与重试。
- 复用现有 Agent v1/v2 解析、时间戳与会话序号校验、人工控制优先级及重连。
- 保留 40 秒回放，第 34 秒模拟入睡；入睡停止引导，光丝向内靠拢并淡去。普通 end 也会淡出，但不被标记为入睡。
- 独立 HTML 使用同一首页源码与构建 CSS 导出，无外部资产依赖。

## 动画输入映射

| 字段 | 作用 |
|---|---|
| mode | 安定、舒展、交织、起伏、呼吸五种运动组织；协议枚举未变 |
| intensity | 光丝流动亮部的强弱 |
| noise / turbulence | 连续交叠与局部错位 |
| speed | 主体波形运动速度 |
| deformation / frequency | 起伏幅度与空间频率 |
| glow / pulse | 内光、光丝可见程度与呼吸幅度 |
| particle_* | 独立粒子密度、扩散、流速、尺寸、亮度；密度为零时隐藏 |
| line_* | 增强光丝密度与亮度、整体起伏与沿线流速；基础光丝保留主体轮廓 |
| hue | 在选定雾蓝与桃金配色上的克制冷暖偏移 |
| transition_sec | 模式过渡时长（最少 1 秒）及连续参数平滑时间尺度 |

## 验证与边界

- TypeScript 检查、生产构建及已有协议/回放回归检查。
- 完整宽屏曲线几何有限性、单位球约束与连续线段检查。
- 光丝、粒子、内光三组着色器经过 EGL/GLES 编译和链接检查。
- 未做浏览器视觉验收、手机性能实测或真实传感器端到端联调。
- 图形是概念 ① 的程序化实现，不能承诺与静态生成图逐像素一致。

## 本地交付

可直接打开独立 HTML 体验。已有源码项目的使用者，也可用本轮交付 ZIP 中的 `frontend` 文件覆盖对应项目文件（解压前备份本机改动）；依赖清单与锁文件未修改。重新启动本地开发服务后生效。后端连接输入 `ws://127.0.0.1:8000/ws/control`（前后端同机、本地页面），远程 HTTPS 页面需使用 WSS。
